책 추가하기

    책 검색 설정

    책 검색은 카카오(다음 책) 데이터를 써요. 카카오 개발자 콘솔에서 앱을 하나 만들고 REST API 키를 붙여넣어 주세요. 키는 이 기기의 브라우저에만 저장되고 깃허브에는 올라가지 않아요.

    반납했어요

    메모와 책갈피 기록은 그대로 남아요.

    분류 관리
